# Architektura licznika osób

Model architektury projektu „Liczenie osób w jednej strefie” w Structurizr DSL.

| Plik | Zawartość |
|---|---|
| `workspace.dsl` | Model i sześć widoków: kontekst, kontenery, wnętrze aplikacji, przetworzenie klatki, wdrożenie Nano, testy na telefonie |
| `docs/` | Opis każdego widoku i przegląd decyzji |
| `decisions/` | Decyzje LP-0001–LP-0005 w formacie ADR |
| `podglad.md` | Polecenie lokalnego podglądu |
| `przeglad.md` | Wynik przeglądu z 28 listopada 2026 i pytania do decyzji |

Widok startowy to `LP-Kontekst`. W podglądzie po diagramach otwórz Documentation, a potem Decisions.
